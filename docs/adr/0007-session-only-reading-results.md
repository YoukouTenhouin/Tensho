# Session-only reading results

Per-tab reading results, expansion state, and panel scroll position belong in browser-session storage so closing the panel or restarting the background worker does not erase completed work. A different document, reload, or browser restart clears these results; settings persist locally, with no persistent selected text or lookup history. This deliberately gives up durable lookup reuse while preserving reading continuity within a session, as agreed in [issue #9](https://github.com/YoukouTenhouin/Tensho/issues/9).

Reading results share a 6 MiB storage budget, evicting the least recently viewed inactive tab's result first and explicitly explaining the loss when that tab is revisited; eviction never initiates a request. A separate persistent dictionary-index cache has a 24-hour lifetime: an expired index must refresh before new resolution, and refresh failure is a technical failure. Interrupted requests require explicit retry after worker restart; completed results remain available.

If a new article cannot fit after eligible eviction, preserve existing results, explain that the article could not be retained, and offer its validated source link. Same-document navigation retains results; if the original focus target has disappeared, return focus to the source page without deliberately changing its scroll position. These bounded retention rules qualify #7's earlier unconditional restoration promise. Native sidebar visibility is separate: Latin v1 permits explicit reopening when Edge does not restore the panel on a tab switch, while restoring retained content and reading position.
