# Preserve uncertainty in dictionary mapping

The extension is a convenient reading aid, and exhaustive dictionary coverage is not a requirement: learners can investigate further themselves. Following the wrong-homograph result in the [Latin integration research](../research/alpheios-latin-integration.md), retain the dictionary alternatives found by a validated resolver without filtering or ranking them using inferred grammatical or semantic correspondence; automatically select only when an exact identity mapping is verified. Mark alternatives and unavailable results explicitly, without presenting the available alternatives as exhaustive.

When analysis supplies no stable lemma identity, preserve each candidate's boundaries within its response and leave stable identity unknown. Same-spelling candidates remain separate, while multiple meanings within one supplied candidate remain together; response-local references must not become invented durable lemma identities.

An unresolved dictionary mapping preserves analysis and is reported as an inability to identify a matching dictionary entry, not as proof that the dictionary has no entry. Unresolved mapping alone does not advance the fallback chain; actual technical failures retain [ADR 0001](0001-separate-analysis-and-dictionary-roles.md)'s fallback behavior. These decisions were accepted during [issue #5](https://github.com/YoukouTenhouin/Tensho/issues/5)'s reopened design interview; they do not establish that the provisional Alpheios Whitaker and Lewis & Short integration has passed validation.

Investigate retaining these services first, reopening provider selection if the revised integration fails validation. Adoption does not require proving the provider's no-entry contract, provided the integration never reports definitive absence without evidence: an index miss remains unresolved mapping, and HTTP failures remain technical failures. Validate ordinary lookups and known ambiguity cases such as `legi` and `malum`, without requiring exhaustive coverage; any confirmed no-entry outcome still stops fallback under ADR 0001. This revises the research gate's earlier mandatory no-entry evidence requirement, while leaving the other integration checks in place.
